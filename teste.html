Estou a desenvolver um sistema de Biblioteca Digital Inteligente. ### Funcionamento do sistema Tenho uma página que apresenta vários livros em formato de cartões (cards). Cada card contém: responde ok * imagem do livro; * título; * autor; * estado (Disponível); * botão "Ver detalhes"; * botão "Reservar". Quando o utilizador clica em **Reservar**, o JavaScript cria um objeto com os dados do livro: * título; * autor; * imagem; * estado. Depois guarda esse objeto no LocalStorage através da chave: ```javascript localStorage.setItem("livroSelecionado", JSON.stringify(livro)); ``` Em seguida redireciona para: ```javascript window.location.href = "Requisitar livro.html"; ``` Na página "Requisitar livro.html", o JavaScript executa: ```javascript const livro = JSON.parse(localStorage.getItem("livroSelecionado")); ``` Depois mostra: * capa do livro; * título; * autor; * descrição; * estado. Até aqui tudo funciona. ### O problema Na primeira vez: 1. clico em Reservar no Livro A; 2. a página de requisição mostra corretamente: * capa do Livro A; * título do Livro A; * autor do Livro A. Tudo correto. Depois volto para a página dos livros. Agora clico em Reservar no Livro B. O esperado seria aparecer: * capa do Livro B; * título do Livro B; * autor do Livro B. Mas isso não acontece. Continua a aparecer: * capa do Livro A; * título do Livro A; * autor do Livro A. Ou seja, parece que o LocalStorage continua com os dados do primeiro livro. ### Informações importantes * Cada card possui o botão: ```html ``` * O JavaScript adiciona o evento usando: ```javascript document.querySelectorAll(".btnReservar").forEach(...) ``` * O objeto do livro é obtido através de: ```javascript const card = e.currentTarget.closest(".card"); ``` Depois: ```javascript card.querySelector("img") card.querySelector("h3") card.querySelector(".autor") ``` Não utilizo IDs repetidos nos cards.
